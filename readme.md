# js-warioware-mini-game

Ce projet d'école a été réalisé dans le cadre du cours de gestion de projet avec un groupe de 11 élèves dont 9 développeurs, 1 Chef de projet/Product owner et 1 Tech Lead.

## Convention du Projet

### Branche

Pour ce projet, la branche de développemement par défault est la branche "DEV".
Chaque branche est relié a une issue créée au préalable, la branche doit se nommer comme tel :

[Première lettre du nom de famille en majuscule]+[Première lettre du prénom en majuscule]-[Nom de la fonctionnalité]

Exemple : "MB-Readme"

### Commit

Deux type de commit peuvent être fait, les noms des commit doivent être fait de la façon suivante :

- feat[Readme]: Création du readme
- fix[Acceuil]: bug dans le header

### Merge Request

Le nom de la merge request doit être le nom de la branche.
Le contenue d'une merge request doit contenir une image de l'ajout ou tu bug ainsi qu'une description et le nom du jeux si ça en est un.
